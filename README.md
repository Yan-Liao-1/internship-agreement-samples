# 实习协议示例集

一批**虚构的**大学生实习协议，用来试用「实习协议审阅助手」这个数字员工——手里暂时没有真实协议的同学，可以直接拿这些去试。

> **所有协议均为虚构示例，单位、人名、学校、地点全部脱敏，不指向任何真实主体。**

---

## 为什么要提供这些

很多同学想试试这个工具，但手上没有实习协议——没签过、或者签完就找不到了。工具再好，也没东西可喂。

所以这里放了 25 份写好的示例协议。挑一份下载，发给数字员工，就能看到完整的审阅报告长什么样。

---

## 怎么用

**第一步**：从下面的表里挑一份，下载 Word 或 PDF。

**第二步**：打开 WPS Comate 客户端，找到数字员工「实习协议审阅助手」。

**第三步**：把文件发过去（也可以直接上传截图，或者把正文粘贴过去）。

**第四步**：它会问你几个小问题——实习类型、现在什么阶段、单位性质、最在意哪一块。点一下就行。

然后等着收报告。报告里会写清楚哪一条有问题、为什么有问题、该找谁确认，最后还附一段可以直接复制发给 HR 的话术。

## 这些协议是谁写的

是为了测试和示范而写的**虚构示例**，不是从任何真实协议改的。单位名一律写成「某某科技有限公司」这种形式，乙方一律是「张某」、学号写成 `2023XXXXXXXX`。

它们不会、也不能用来主张任何真实权利义务。**请不要拿它们去冒充真实协议。**

---

## 关于「实习协议审阅助手」

一个跑在 WPS Comate 上的数字员工：上传协议，它给你一份六章的报告——哪里有问题、为什么有问题、该问谁、怎么开口问。

它背后是一套整理好的审阅规则（63 条，分八个方面）、四个知识库（27 份文档），每一条判断都能顺着往回倒推到法规条文号，查不到出处的不会写。

**它不做 AI 律师**——不给法律结论，只给风险提示和「该问什么」。涉及金额大、期限长、或者已经出了纠纷的事，它会建议你去找学校的法律援助中心或专业律师。
